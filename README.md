Front-end for E-commerce Website GoodFood

This project is the front-end implementation of GoodFood, an e-commerce website designed for online food ordering and delivery.
It provides a modern, responsive, and user-friendly interface, allowing customers to:

Browse products and menus using smart filters and voice/image-based search

Interact with an AI-powered Chatbot to ask questions about the website or get assistance

Use the smart ordering function via Chatbot — simply name the product you want and choose your preferred payment method

Add items to the shopping cart

Proceed through a secure checkout process with multiple payment options, including Cash on Delivery (COD), VNPay Gateway, and PayPal

Track orders in real time

The front-end is built with React, TypeScript, and Tailwind CSS, ensuring clean code, scalability, and an optimized user experience across devices.
