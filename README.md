# Front-end for E-commerce Website GoodFood

This project is the front-end implementation of GoodFood, an e-commerce platform designed for online food ordering and delivery.
It provides a modern, responsive, and user-friendly interface, allowing customers to:

Browse products and menus

Add items to the shopping cart

Proceed through a secure checkout process

Track their orders in real time

The project is built with React, TypeScript, and Tailwind CSS, ensuring clean code, scalability, and an optimized user experience across devices.
